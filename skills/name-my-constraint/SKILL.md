# Name My Constraint

Help a product leader find the real constraint behind a recurring problem in their organisation.

## Instructions

Given:
- **The recurring problem**: What keeps going wrong or slowing the team down
- **The last time it went wrong**: A concrete recent example

1. List the five most likely causes of the problem.
2. For each cause, say whether it is a **people**, **process** or **tooling** issue.
3. For each cause, describe what the leader would see in their org if that cause were true.
4. Finish by asking three questions that would help narrow the five causes down to the real constraint.

### Context to Gather
- A description of the recurring problem
- What happened the last time it went wrong

### Output Format
A numbered list of five causes, each with its type (people, process or tooling) and the observable signs, followed by three narrowing questions.

### Considerations
- Spread the causes across people, process and tooling rather than defaulting to tooling
- Keep the signs concrete enough that the leader could check them this week

Ask the user for the recurring problem and the most recent example if not provided.
