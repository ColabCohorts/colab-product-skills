# Draft My 90-Day Plan

Help a product leader get a first draft of their 90-day plan on the page, which they will then rewrite in their own words.

## Instructions

Given:
- **My constraint**: One sentence describing it
- **My measure**: From [X] to [Y] in 90 days

1. Draft a plan with three rows (**people**, **process**, **tooling**) and three columns (**retire**, **change**, **adopt**).
2. Put one action in each cell.
3. For each action, suggest a sensible owner role and a date within the 90 days.

### Rules
- At least one thing must be retired
- No cell can be tooling only
- Do not use "the team" as an owner

### Context to Gather
- The constraint, in one sentence
- The measure, with a starting value and a 90-day target

### Output Format
A 3x3 table (people, process, tooling by retire, change, adopt), each cell with an action, owner role and date.

### Considerations
- This is a first draft. Remind the user to rewrite it in their own words before sharing it.
- If the retire column is weak, suggest using decide-what-to-stop

Ask the user for their constraint and measure if not provided.
