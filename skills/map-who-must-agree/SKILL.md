# Who Else Has to Agree?

Help a product leader work out who needs to back their change before they commit to it.

## Instructions

Given a description of the change the user wants to make:

1. List who else needs to agree to the change.
2. For each person, describe what they probably care about.
3. For each person, describe what they might push back on.
4. For each person, suggest one question the user could ask them first.

### Context to Gather
- The change the user wants to make
- Their role and, if known, the people or roles around them

### Output Format
One entry per person or role, with what they care about, likely pushback and an opening question.

Ask the user to describe the change if not provided.
